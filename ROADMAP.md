# Дорожная карта развития платформы OZIZ (ROADMAP)

## Этап 1: Production MVP (Текущий релиз)
- [x] Подача обращения за 3 касания (фото, GPS-метка, 1-клик отправка).
- [x] Мультимодальный ИИ-анализ на базе Gemini 3.8 Flash Vision со строгой схемой JSON.
- [x] Обогащение контекстом погоды Open-Meteo (осадки, гололед, температура).
- [x] Объяснимая формула расчета приоритета с разложением по факторам.
- [x] Интерактивная карта (темная тема, тепловая карта концентрации дефектов, кластеризация).
- [x] Смарт-контракт Anchor на Solana (Append-only архитектура, цепочка хэшей).
- [x] Панель оператора диспетчерской службы с контролем регламентов SLA.
- [x] Публичный рейтинг городских служб и дашборд открытых данных (GeoJSON, CSV).
- [x] Полный набор из 30 предзаполненных тестовых обращений по районам города.

## Этап 2: Масштабирование инфраструктуры и Web3-инновации (Q1–Q2 2027)
- [ ] **Squads Multisig Управление:** передача права обновления смарт-контракта в децентрализованный совет из представителей гражданского общества, урбанистов и акимата (3 из 5 подписей).
- [ ] **Пространственное шардирование H3 (Uber H3 Index):** переход на гексагональную сетку 8-го и 9-го уровней для моментального кластерного поиска дубликатов в радиусе 100 метров прямо в базе данных PostGIS.
- [ ] **Децентрализованное хранилище Arweave:** постоянное бессрочное хранение медиа-доказательств с фиксацией Permaweb URL.
- [ ] **Zero-Knowledge Доказательства (zk-SNARKs):** доказательство нахождения гражданина в пределах 50 метров от места инцидента без раскрытия его точного местоположения и истории перемещений.

## Этап 3: Государственная интеграция и автоматизация (Q3–Q4 2027)
- [ ] **Интеграция с платформой e-Otinish / Smart Astana / Smart Almaty:** двусторонний шлюз для автоматической генерации входящих номеров в официальных СЭД акиматов.
- [ ] **Автоматические финансовые штрафы за срыв SLA:** смарт-контракт депонирует страховой депозит подрядчика и автоматически начисляет пени в фонд благоустройства района при подтвержденной просрочке.
- [ ] **Edge AI для автономных дронов и инспекционных автомобилей:** предварительный локальный скрининг дефектов асфальта на дорожных камерах в реальном времени.
