# OZIZ — GPS-платформа гражданских обращений с ИИ-анализом и реестром на Solana

[![Solana Devnet](https://img.shields.io/badge/Solana-Devnet-14F195?logo=solana&logoColor=white)](https://explorer.solana.com)
[![Anchor 0.29](https://img.shields.io/badge/Anchor-0.29.0-6366f1)](https://project-serum.github.io/anchor/)
[![Gemini 3.8 Flash Vision](https://img.shields.io/badge/AI-Gemini%203.8%20Flash-4285F4?logo=google)](https://ai.google.dev)
[![Open-Meteo](https://img.shields.io/badge/Weather-Open--Meteo-38bdf8)](https://open-meteo.com)

**OZIZ** — полнофункциональная децентрализованная платформа для подачи и мониторинга городских обращений (ямы, открытые люки, неработающие фонари, стихийные свалки, поваленные деревья, подтопления).

Главная цель проекта — **полная прозрачность и подотчетность властей**. Ни одна жалоба не может быть «тихо» удалена или закрыта без отчета: каждый шаг жизненного цикла необратимо фиксируется в блокчейне Solana с криптографической цепочкой хэшей.

## 🚀 Быстрый запуск за 3 минуты

### Вариант 1: Локальный запуск (Node.js)

1. Клонируйте репозиторий и установите зависимости:
   ```bash
   npm install
   ```

2. Установите переменные окружения (опционально для своего ключа Gemini):
   ```bash
   cp .env.example .env
   ```
   *Примечание:* Приложение снабжено надежным эвристическим fallback-модулем, поэтому запускается и работает на 100% даже без указания внешних ключей API!

3. Запустите full-stack сервер:
   ```bash
   npm run dev
   ```

4. Откройте в браузере:
   ```
   http://localhost:3000
   ```

### Вариант 2: Запуск через Docker Compose

```bash
docker-compose up -d --build
```

### Запуск тестов смарт-контракта Anchor:
```bash
npx tsx tests/civic_registry.ts
```

## 🌟 Ключевые возможности

1. **Сценарий подачи за 3 касания (Mobile-First):**
   - **Фото дефекта:** Клиентское сжатие в HTML5 Canvas до 1600px, автоматическое удаление метаданных EXIF (защита приватности).
   - **GPS-локация:** Высокоточное позиционирование (`enableHighAccuracy`) с радиусом погрешности и ручной корректировкой метки на интерактивной карте.
   - **Отправка:** Опциональный комментарий или голосовой ввод через Web Speech API.

2. **Мультимодальный ИИ-анализ (Gemini 3.8 Flash):**
   - Точная классификация дефекта по 11 категориям.
   - Оценка тяжести (Severity 1..5) и угрозы для пешеходов/водителей/детей.
   - Оценка метрических габаритов дефекта.
   - Проверка смысловой согласованности текста и фото (защита от спама и ложных жалоб).
   - Мгновенное детектирование ЧС (`is_emergency = true` для открытых колодцев и упавших деревьев).

3. **Обогащение контекстом Open-Meteo:**
   - Автоматический запрос осадков, температуры, ветра и заморозков без платных ключей с 15-минутным координатным кешем.

4. **Объяснимая формула приоритета:**
   - Детерминированный прозрачный расчет с показом вклада каждого фактора (ИИ-тяжесть, близость школ/больниц, погода, трафик, подтверждения жителей, возраст проблемы).
   - Градации: `CRITICAL (≥85)`, `HIGH (65–84)`, `MEDIUM (40–64)`, `LOW (<40)`.

5. **Неизменяемый реестр на Solana (Anchor):**
   - **Строго Append-Only:** Программа не содержит инструкций `update`, `delete` или `close`.
   - **Криптографическая цепочка хэшей:** Каждое событие статуса ссылается на `prev_event_hash` предыдущего.
   - **Защита от необоснованных отказов:** Служба не может поставить статус `REJECTED` без обязательного текстового обоснования (хэш записывается ончейн).
   - **Интерактивный аудит:** Кнопка «Проверить неизменяемость» в реальном времени сравнивает базу данных с цепочкой хэшей Solana.

6. **Диспетчерская городских служб и контроль SLA:**
   - Очередь обращений по 6 службам (Дорожники, Освещение, Водоканал, ЖКХ, Зеленстрой, ЧС 112).
   - Таймеры обратного отсчета регламентов SLA и автоматическая фиксация срывов сроков.
   - Звуковые оповещения о поступлении критических обращений в реальном времени по Server-Sent Events (SSE).

7. **Гражданский контроль и открытые данные:**
   - Подтверждение «Я тоже вижу (+1)».
   - Голосование за качество ремонта («Починено» / «Не починено»). При кворуме недовольных заявка автоматически переоткрывается с пометкой брака.
   - Публичный рейтинг открытости служб и антирейтинг нарушителей SLA.
   - 1-клик экспорт в открытые форматы **GeoJSON** и **CSV**.
   - Трехъязычный интерфейс: **Русский | Қазақша | English**.

## 🎬 Демо-сценарий проверки

1. **Создание обращения:**
   - Нажмите кнопку **«Сообщить о проблеме»** в шапке.
   - Выберите шаблон **«Яма на дороге»** или **«Открытый люк (SOS)»** (либо загрузите свое фото).
   - Нажмите **«Отправить и закрепить в Solana»**.
   - Наблюдайте 5-этапный индикатор: очистка EXIF ➔ анализ Gemini ➔ погода Open-Meteo ➔ приоритет ➔ минтинг в Solana.

2. **Просмотр карточки дефекта:**
   - Кликните на маркер на карте или на карточку в ленте.
   - Ознакомьтесь с подробным разложением формулы приоритета и заключением ИИ.
   - Нажмите **«Я тоже вижу (+1)»** — приоритет увеличится в реальном времени.

3. **Проверка неизменяемости в Solana:**
   - В блоке «Реестр Solana» нажмите кнопку **«Запустить аудит неизменяемости»**.
   - Система подтвердит целостность криптографической цепочки событий.
   - Нажмите ссылку **«Solana Explorer Devnet»** для перехода в публичный обозреватель.

4. **Работа оператора службы:**
   - Перейдите во вкладку **«Диспетчерская служб»**.
   - Нажмите **«В работу»**, а затем **«Устранено»** с прикреплением фото ремонта.
   - Обращение обновит статус и запишет транзакцию в Solana.

5. **Голосование жителей:**
   - В карточке устраненного дефекта нажмите **«Починено ✓»** (запустится салют конфетти) либо **«Не починено ✕»** (жалоба автоматически переоткроется как бракованная).
